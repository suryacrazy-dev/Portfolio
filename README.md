# ⚡ Surya — WordPress & Front-End Developer Portfolio

[![Portfolio Banner](images/surya_web_developer.png)](http://localhost:3000/)

## 🌟 Key Features & Architecture

- **🎨 Modern Luxury Design System**: Custom typography pairing using *Fjalla One* and *Gilroy*, featuring high-contrast black & white tones, glassmorphism elements, and an Angular Geometric 'S' monogram logo.
- **⚡ Smooth Locomotive & GSAP Motion**: Integrated Locomotive Scroll v4 with GSAP ScrollTrigger for parallax scrolling, mask text reveals, and dynamic mouse-follower cursor spotlight.
- **📱 100% Multi-Device Responsiveness**: Tailored layout adaptation with fluid typography across Mobile, Tablet, Laptop, and Desktop screens.
- **👤 Editorial Bio & Experience Section**: Features a floating location badge (`📍 Bangalore, India`), a comprehensive professional summary detailing 3 years of experience, and a dedicated experience timeline.
- **🛠️ Black & White Tech Skills Bento Matrix**: 5-domain categorization featuring interactive technology pill badges:
  - **(01) WordPress & CMS**: WordPress, Elementor, WooCommerce, ACF, Plugins
  - **(02) Front-End Development**: HTML5/CSS3, JS (ES6+), React/Next.js, TypeScript, GSAP
  - **(03) UI & State Management**: Responsive UI, Bootstrap, Tailwind CSS, Redux Toolkit
  - **(04) Performance & SEO**: Web Vitals, Image Opt, SEO, Lazy Loading
  - **(05) Tools & Workflows**: Git/GitHub, npm, Figma/Canva, DevTools
- **🖼️ Full-Screen Lightbox Modal**: View high-resolution certificates (e.g., Microsoft Technology Associate) with dark blur backdrop and `Escape` key controls.
- **📩 Interactive Contact Form**: Built-in client-side form submission handler with inline `#submit-success` confirmation card.

## 💻 Local Setup & Development Guide

Follow these simple steps to run the portfolio locally on your computer:

1. **Launch Development Server**:
   Using Python 3:
   ```bash
   python3 -m http.server 3000
   ```
   Or using Node.js `npx`:
   ```bash
   npx serve .
   ```

2. **View Live Project**:
   Open your browser and navigate to `http://localhost:3000/`.

---

## 🌐 Deploying to Production

This project is zero-dependency static HTML/CSS/JS and can be deployed instantly to **Vercel**, **Netlify**, or **GitHub Pages**.

### Deploying via Vercel CLI:
```bash
npx vercel --prod
```
